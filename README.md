# ImmoInvest Viewer

**Online öffnen: https://newtro2030.github.io/immoinvest-viewer/**

Viewer für die JSON-Exporte der Immobilien-Linkanalyse (Schema 1.0): Einzelansicht mit Gesamturteil, Belegstatus, Szenarien und Risiken, Vergleich mehrerer Objekte sowie eine Prüfung der Exporte gegen den Datenvertrag.

- JSON-Dateien in die Seite ziehen oder „Fiktive Beispiele laden“ wählen.
- Die Dateien werden ausschließlich im Browser gelesen; nichts wird hochgeladen.
- Die Datei `index.html` funktioniert auch offline per Doppelklick.

Die Beispiele in `beispiele/` sind fiktiv und beschreiben keine realen Objekte.

Dieses Repository enthält nur die veröffentlichte Fassung. Sie wird aus einem privaten Repository erzeugt; Änderungen direkt hier werden beim nächsten Veröffentlichen überschrieben.
